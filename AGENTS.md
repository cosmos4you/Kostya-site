# GagraFly — сайт тандемных полётов на параплане (gagrafly.ru)

Инструкция для любых ИИ-агентов (Codex, Claude и др.), работающих с репозиторием.

## Что это
Статический сайт без сборки. Хостинг — GitHub Pages, домен `gagrafly.ru` (файл `CNAME`).
**Деплой = push в ветку `main`.** Через 1–2 минуты изменения на https://gagrafly.ru/.

## Источник правды
- `index.html` — главная (вся разметка и тексты).
- `styles.css` — базовые стили.
- `effects.css` — подключается ПОСЛЕ `styles.css` и переопределяет его. Мобильные фиксы — в конце, блок «МОБИЛЬНАЯ ВЁРСТКА».
- `effects.js` — анимации, формы, счётчики.
- `chto-posmotret-v-gagre/`, `gora-mamdzyshkha/` — SEO-страницы.
- `sitemap.xml`, `robots.txt`, `site.webmanifest`, `yandex_*.html` — SEO/верификация, не удалять.
- `gallery/`, `images/`, `photos/` — картинки (jpg/png + webp в размерах 400/800).
- `video/` — ролик «как выглядит полёт» (flight.mp4 H.264 без звука, автозапуск по кругу + постер). Исходник лежит локально и не в репозитории.

## Важные правила
- На десктопе `body { zoom: 0.85 }`; на мобиле (≤720px) он сброшен в 1 — этот сброс не удалять.
- Не удалять `CNAME` — иначе отвалится домен.
- Секретов в репозитории нет и быть не должно (репозиторий публичный). Токен Telegram-бота живёт только в переменных Railway.
- Не мержить ветку `codex/clean-site` в `main` без проверки: она удаляет `sitemap.xml`, `robots.txt`, `site.webmanifest` и верификацию Яндекса.

## Заявки с форм
Сайт → POST на обработчик `backend/relay/server.js` (Node, Railway; переменные `BOT_TOKEN`, `CHAT_ID`) → Telegram Косте через @gagraflybot. Резерв — WhatsApp. `backend/telegram-relay.gs` — старый вариант (Google Apps Script).

## Что НЕ в репозитории (локально у владельца)
Исходные фото («Фото для сайта Кости», ~180 МБ), «Сертификат», старые черновики «Kostya cite», «Kostya cite 2», `data/`. Они в `.gitignore` намеренно; на сайт идут только оптимизированные копии из `gallery/` и `images/`.

## Локальный просмотр
```bash
python3 -m http.server 8000   # из корня репозитория, открыть http://localhost:8000
```

## Аналитика
Яндекс.Метрика, цель `booking` (срабатывает по факту доставки заявки).
